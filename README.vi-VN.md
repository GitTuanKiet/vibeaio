# Vibeaio

Cài một lần cho **stack vibecoding** đã chọn lọc: clone/symlink skills, deps, và cài công cụ từ catalog JSON ([`catalog/catalog.json`](catalog/catalog.json)).

## Cài nhanh

```bash
curl -fsSL https://raw.githubusercontent.com/GitTuanKiet/vibeaio/master/setup.sh | bash
```

## Lệnh trong repo

- `bun run setup:catalog` — cài/cập nhật catalog có hướng dẫn
- `bun run typecheck` — kiểm tra TypeScript
